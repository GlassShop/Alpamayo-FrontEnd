# API local de desarrollo

Datos de prueba para usar el frontend mientras el servidor real no existe (sprint 2).
No es código: los precios los cambia el CEO desde `/catalogo/precios` y json-server los guarda en `db.json`.

```bash
npm run api   # http://localhost:3000/api/v1
```

Los datos de arranque son los de los casos de prueba del Excel (laminado cielo 6 mm a S/ 8.00 y espejo doble 4 mm a S/ 6.50, lista Pública).
El color "plateado" del espejo es provisional: corrígelo desde la app si no corresponde.
